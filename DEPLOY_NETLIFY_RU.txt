УСТАНОВКА ИЗ ПОЛНОГО ПРОЕКТА

Этот архив уже содержит правильную структуру папок. Распакуйте архив и переносите содержимое в корень GitHub-репозитория, сохраняя пути и имена. Не загружайте ZIP как единственный файл.

В корне должны находиться package.json, netlify.toml, README_RU.txt и папки apps_script, docs, netlify, scripts, site.

Netlify Build command: npm run build
Publish directory: site
Functions directory: netlify/functions
Node.js: 20

Настройки build и functions уже заданы в netlify.toml. Сборка выполняет локальную проверку комплекта и синтаксиса.

ПЕРЕМЕННЫЕ NETLIFY
Сохраните существующие KUPI_API_SECRET и GAS_WEB_APP_URL. Секреты не добавляйте в GitHub и не помещайте в архив.

ВАЖНО ДЛЯ ОБНОВЛЕНИЯ GITHUB
Загрузка файлов с теми же путями обновляет соответствующие файлы только если GitHub принимает их как замену и вы фиксируете изменения (Commit changes). ZIP не может заставить GitHub автоматически заменить/удалить файлы. Старые файлы, отсутствующие в этом архиве, останутся в репозитории, пока их отдельно не удалить. Не удаляйте весь репозиторий.

После обновления дождитесь успешного Deploy в Netlify. Затем отдельно обновите Google Apps Script из папки apps_script. Существующий Apps Script проект и его URL сохраняйте.

Kaspi-платёж в этой версии подтверждается редактором вручную; автоматической проверки оплаты нет.
