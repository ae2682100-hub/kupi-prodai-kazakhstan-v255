Поэтому реальная запись в таблицу, реальная загрузка в Drive, отправка OTP-письма и фактический запуск триггера не объявляются проверенными. Их проверяет endpoint /api?action=health (связь с Apps Script) и последующий тест после установки.

Критическое ограничение публикации: Netlify должен выполнить build pipeline для упаковки Functions. При Git-based deployment это происходит автоматически. Разовая загрузка только папки site публикует только статические страницы.

Повторная проверка v2.5.6: сборочный сценарий дополнительно проверяет все 21 обязательный файл, наличие 17 серверных действий API и ключевые параметры Netlify.
