КУПИ-ПРОДАЙ — КАЗАХСТАН v2.5.7
ИНСТРУКЦИЯ ДЛЯ ОБНОВЛЕНИЯ GITHUB

Архив содержит уже восстановленную структуру проекта. В корне архива находятся package.json и netlify.toml, а также папки apps_script, docs, netlify, scripts и site.

Переносите файлы в корень репозитория kupi-prodai-kazakhstan-v255, сохраняя структуру каталогов. Не загружайте ZIP как один файл и не переносите содержимое папок в корень без их папок.

ОБРАТИТЕ ВНИМАНИЕ
- Совпадающие пути и имена — это файлы, которые требуется обновить.
- Новые пути — новые файлы, которые добавятся.
- Старые файлы, которых нет в архиве, автоматически не удаляются.
- Сам ZIP не может управлять GitHub и не может гарантировать замену при загрузке. GitHub должен принять изменения и создать commit.

Не удаляйте репозиторий и не очищайте его целиком. Если мобильная страница GitHub не позволяет заменить папку/файл с тем же путём, остановитесь и сообщите, что именно показывает экран — подберём безопасный способ обновления.

После загрузки проверьте список файлов по GITHUB_FILES_LIST_RU.txt. Затем дождитесь сборки Netlify. Google Apps Script обновляется отдельно из папки apps_script.
